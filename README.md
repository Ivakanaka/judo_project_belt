# Сдача на пояс

`index.html` — согласованный прототип в одном файле. Откройте его в браузере и выберите «Участник», «Настройки формы» или «Ведомость участников». Для запуска достаточно браузера. В ведомости кнопка «Печать» открывает печать A4.

В прототипе можно заполнить заявку, изменить параметры мероприятия, заменить логотип и отсортировать ведомость. Есть базовая адаптивная вёрстка. Заявки и настройки хранятся в памяти открытой страницы, сбрасываются после перезагрузки и не передаются между устройствами. Встроенная ведомость содержит демонстрационные записи.

## Как начать работу

1. Распакуйте архив. Загрузите `index.html` и `README.md` в нужную ветку приватного репозитория. Если в ветке уже есть сайт или свой `README.md`, положите оба файла в отдельную папку `judo-pisa`.
2. Сохраните их отдельным коммитом `Add judo registration prototype`.
3. Подключите репозиторий в Codex Cloud, выберите ветку с этим коммитом и отправьте задание ниже. Проверьте результат в отдельном pull request.

## Первое задание для Codex

> Прочитай README и найди существующий прототип в index.html рядом с ним. Доработай его мобильную вёрстку, в первую очередь экран «Участник». Используй текущий HTML, CSS и JavaScript. Сохрани согласованный дизайн, сценарии формы, настройки, ведомость и печать A4.
>
> Проверь ширины 320, 390 и 430 px и десктоп 1280 px. На телефоне проверь обложку с логотипом, поля при открытой клавиатуре, выбор пояса, согласия, ошибки, успешную отправку и материалы. На десктопе прогони замену логотипа, сортировку и печать ведомости. Убедись, что новая заявка появляется в ведомости в той же вкладке. Укажи, какие сценарии и на каких устройствах проверил. Сервер и публикацию оставь отдельным этапом.

## Проверка перед пилотом

| Этап | Как проверить | Что считать успехом |
| --- | --- | --- |
| Мобильный прототип | Открыть по тестовой ссылке на iPhone и Android. Дать нескольким людям заполнить форму вымышленными данными. | Участники самостоятельно находят нужный пояс, исправляют ошибки и доходят до подтверждения. |
| Сквозной тест | Подключить серверное сохранение и вход администратора. Отправить заявку с телефона, открыть ведомость на другом устройстве и обновить страницу. | Заявка появилась в ведомости, пережила обновление и попала в печать. С экрана участника ведомость недоступна. |
| Пилот клуба | Взять один поток, проверить приём заявок и печать A4 на реальном принтере. | Администратор получает ведомость, по которой можно провести аттестацию. |
